9. settings
        change company settings like name logo etc
    Currencies
        add multiple Currencies rather then a default one
    customer group
        add customer groups, like "Retail", "Wholesale", etc.
        we can also add benefits or discounts for each group. like 10+ to a specific group.
    units
        allow us to create a custom unit, like for 3000PC a unit 1 or so
    Brands
        manage brands which we are working with
    Variants
        allow to add different Variants of a product, like a color or size
    warehouse
        allow us to manage multiple warehouses
    Email templates
        works as our smtp
    group permissions
        allow us to set permissions for each group and manage custom groups
